## Giới thiệu

**EduHub** là nền tảng quản lý khoá học, thành viên và đăng ký học.
Repo này ghi lại phần Back End của hệ thống qua từng chương: thiết kế cơ sở dữ liệu, viết truy vấn SQL, xử lý giao dịch, và dần xây dựng API phục vụ cho ứng dụng.

Dữ liệu cốt lõi gồm 3 nhóm: **Thành viên** (`members`), **Khoá học** (`courses`) và **Đăng ký** (`registrations`).
